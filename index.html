ZIP → GitHub Pages

Выбираешь ZIP с сайтом, деплоер распаковывает архив прямо в браузере и заливает все файлы в GitHub одним commit.

Страница загружена. Нажми «Проверить кнопку».

Работает без внешних библиотек: ZIP распаковывается через встроенный в браузер DecompressionStream. Открывай деплоер по HTTPS через GitHub Pages, а не внутри предпросмотра ChatGPT. Для токена нужны права Contents: Read and write на репозиторий сайта.
